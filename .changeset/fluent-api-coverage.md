Cover the whole query model in the fluent API (#86). `SpatialQueryConfigurator.WithCenter(lat, lng)` sets the centre a geo-distance query measures from, which was always 0,0 before. `FuzzyQueryConfigurator` gains `WithFuzziness`, `WithPrefixLength`, `WithMaxExpansions` and `WithTranspositions`; the first three throw `ArgumentOutOfRangeException` for a negative value. Every sub-query configurator and `BooleanQueryConfigurator` gain `WithBoost`, which throws `ArgumentOutOfRangeException` for a boost of 0 or less. A new `CreateLuceneQuery` builds a `LuceneSubQuery`. The fuzzy, prefix, prefix phrase, range, geo-distance and Lucene `Create…Query` methods are now also available at the top level of `CreateSearchQuery`, without a wrapping bool, and the top-level and nested methods share one implementation. `QueryCreatorConfigurator` gains `SortBy`, `SortByDescending` and `WithProperties`. `CreatePostFilterQuery` adds a bool to `PostFilterQuery`. `HighLighterConfigurator` gains `WithField`, `ForAllFields` and `WithQuery`. `FluentApiSearchQueryCreator.WithSearchQuery` now configures the query passed to the constructor instead of replacing it with a new one. Breaking: `CreateHighlighterQuery(Action<HighLighterConfigurator>)` loses the type parameter it never used, so a call that named one no longer compiles, and the unused `FluentQueryConfigurator.PostFilterQuery` property is removed; use `CreatePostFilterQuery`.
